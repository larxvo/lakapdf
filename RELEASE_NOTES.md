# LakaPDF 0.3.1 Alpha — Windows

© 2026 Larx Vo — vovinhlac.com

Offline self-contained Windows installer. No end-user Python required. Alpha functions: PDF open/view, page navigation, search, text selection, region reconstruction, annotation, page rotate/delete/merge/split, PNG export, visual signature image, save PDF.

**Known limits:** Not native PDF text editing; not OCR or certificate signing. Unsigned EXE may trigger SmartScreen. Do not disable Windows security.
