## Name
LakaPDF

## Short description
Free, local-first PDF editor for Windows. View, annotate, organize and save PDF documents on your computer.

## English description
LakaPDF is a free Windows desktop PDF application created by Larx Vo. Open PDF files, browse and zoom pages, search for text, inspect fonts, highlight content, add simple text, rotate or delete pages, merge or split PDFs, export PNG images, insert visual signature images and save as PDF.

No subscription, mandatory account, forced watermark or cloud document upload is required.

**Alpha limitations:** selected text replacement reconstructs a region and may alter its layout; it is not full native Acrobat-style editing. A visual signature image is not a digital certificate signature. OCR, PDF/A and PDF/X are not yet available. Keep copies of important documents.
