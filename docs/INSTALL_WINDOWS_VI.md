# Cài LakaPDF trên Windows

1. Vào https://github.com/larxvo/lakapdf/releases
2. Sau khi GitHub Actions build thành công, tải `LakaPDF_0.3.1_Windows_x64_Setup.exe`.
3. Kiểm tra SHA-256, quét Microsoft Defender rồi chạy bộ cài.
4. Mở LakaPDF từ Start Menu. Không cần cài Python.

**Bảo mật:** bộ cài chưa ký số. Windows SmartScreen có thể cảnh báo. Không tắt Defender. Để phát hành rộng rãi cần chứng thư code signing.
